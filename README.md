# SQL Data Analysis Portfolio

### Microsoft SQL Server | T-SQL | Database Management | Data Analysis

## About This Repository

Welcome to my SQL Data Analysis Portfolio!

This repository contains a collection of SQL scripts and practice projects developed while learning and applying SQL for database management, data manipulation, and business data analysis.

The projects demonstrate my understanding of relational databases, SQL queries, data relationships, aggregation functions, and stored procedures using Microsoft SQL Server (T-SQL).

## Technologies Used

- **Database:** Microsoft SQL Server
- **Language:** SQL (T-SQL)
- **Concepts:** Relational Database Design, Data Manipulation, Joins, Aggregations, Subqueries, and Stored Procedures

## Projects and SQL Files

### 1. Employee Database Management

**File:** `mysqlquery1.sql`

This script focuses on creating and managing an employee database.

**Concepts covered:**
- Creating relational database tables
- Primary keys and foreign keys
- Employee and department relationships
- Salary grades
- SQL data types and constraints

### 2. E-commerce Database Design

**File:** `project1query.sql`

Designed a relational database structure for an e-commerce business.

**Database tables:**
- Customers
- Products
- Orders
- Order Items
- Payments

**Concepts covered:**
- Relational database schema design
- Primary and foreign keys
- Table creation
- Identity columns
- Relationships between business entities

### 3. E-commerce Data Insertion

**File:** `project2INSERTquery.sql`

Contains SQL INSERT statements to populate the e-commerce database with sample transactional data.

**Concepts covered:**
- INSERT INTO statements
- Bulk insertion of sample records
- Customer and product information
- Order transactions
- Payment records

### 4. E-commerce Sales Analysis

**File:** `project3query.sql`

Contains SQL queries designed to analyze e-commerce business performance.

**Business questions explored:**
- What is the total revenue from delivered orders?
- Which products generate the highest revenue?
- Which customers purchase the most units?
- What are the top-selling products?
- How many orders have been cancelled?

**SQL concepts covered:**
- INNER JOIN and other joins
- GROUP BY
- ORDER BY
- SUM and COUNT
- TOP
- GROUP BY ROLLUP
- Aggregate calculations

*Some analytical queries are currently commented out and will be refined in future updates.*

### 5. SQL Stored Procedure

**File:** `SQLprocedure.sql`

Developed a parameterized stored procedure for employee salary analysis.

**Concepts covered:**
- CREATE PROCEDURE
- Input parameters
- LEFT JOIN
- CASE expressions
- ISNULL
- GROUP BY ROLLUP
- Conditional filtering
- Salary aggregation
